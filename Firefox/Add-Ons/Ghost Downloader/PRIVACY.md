# Ghost Downloader 浏览器扩展（Dox 修改版）：隐私声明

**数据并非只在本机流转。** 此扩展（`ghost-downloader@magi`，1.0.0）是独立维护的非官方 GPLv3 分支。它会把任务交给本机 Ghost Downloader，也可把媒体交给第三方网页；不含开发者遥测。

**第三方在线 FFmpeg（可选，默认不发送）：** Cat Catch 录制工具或扩展有权访问的 HTTP/HTTPS 网页可以发起处理请求。页面消息本身不代表同意。每次都需要你在扩展自己的确认界面允许这一笔传输；拒绝、关闭或不确认时，扩展不会向在线工具发送该笔数据。只有允许后，扩展才会将处理指令、来源页网址、标题、文件名、资源地址以及实际音视频或录制内容（视请求而定）交给 `https://ffmpeg.bmmmd.com/`。即使在浏览器内处理，该第三方网页也能读取这些数据；本扩展无法保证它不会另行传输或保留。

| 操作 | 数据和接收方 |
| --- | --- |
| 识别下载和媒体 | 在获准访问的网站上，扩展观察标签页、页面和资源地址、请求及响应头、文件名、类型和大小；也可读取标题、图片地址和媒体信息。相关快照可能包含 Cookie、Authorization、自定义认证头及带有临时令牌的 URL。高级捕获可处理页面提供的媒体解密密钥。 |
| 连接桌面端 | 默认通过 `ws://127.0.0.1:14370` 连接 Ghost Downloader，并可探测其他本机端口。握手发送协议与扩展版本；认证时另发送配对令牌和安装类型。只与信任的本机服务配对。 |
| 接管下载、发送资源或图片 | 自动接管或手动发送任务时，相关 URL、文件名或标题、来源页、请求头、大小和媒体信息会交给本机配对的桌面端。发送媒体资源时还可能附带同一标签页收集的媒体解密密钥。桌面端可使用这些数据（包括登录凭据）向源网站请求文件，并向扩展返回任务、进度和状态。离线时，待发任务可在浏览器中排队，待连通后发送。 |
| 加载预览和下载文件 | 图片、海报预览、媒体读取和下载可请求原始网站或 CDN。这些服务器可收到 IP 地址和正常 HTTP 请求信息。 |

**本地保存。** 偏好、主题、服务地址和配对令牌保存在扩展本地存储中。资源及请求头快照、待发任务可保存在会话存储中；部分桥接状态在没有会话存储时回退到本地存储。导航或关闭标签页时会清理该标签页的资源列表，但不是撤回已发送的任务。

**隐私窗口。** 此版本不允许在 Firefox 隐私窗口运行，不在这些窗口中识别资源或接管下载。

**你的选择。** 关闭下载接管仅停止自动接管新下载。要阻止扩展在某网站上活动，请撤销相应的网站访问权限（如 Firefox 支持），或禁用扩展。卸载会移除扩展的浏览器本地数据，但不会删除已交给桌面端、源网站或在线 FFmpeg 网页的副本。

问题反馈：[Dox 项目](https://github.com/aenerv7/Dox/issues)。请勿在公开反馈中附上 Cookie、令牌、媒体密钥、私有链接或原始请求头。
