Modified by aenerv7 on 2026-11-27. The extension is separately identified and
built for Firefox. The Firefox fixes incorporated from aenerv7's source branch
fix/firefox-popup-layout-and-downloads (c962609a8dced7e0e8ce09e9bb3b2bc096c68d76):
  1. Restore the popup theme before the first paint to prevent background flashes.
  2. Hand off recognized downloads before Firefox opens its native save dialog.
  3. Keep empty-state icons and text in place when opening or switching tabs.
For this distribution, private windows are excluded and each transfer to the
third-party online FFmpeg tool requires confirmation in an extension page.
